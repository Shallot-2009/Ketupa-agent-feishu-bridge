# 参考功能与独立实现检查

## 范围与方法

比较对象是参考归档中的 `@modelzen/feishu-codex-bridge` 0.6.14（MIT）与本项目独立公开版。参考源码只在内存中用于聚合比对，没有导入、解压到本项目或打包分发；功能目录来自其 README。本项目 Apache-2.0 仅覆盖自己的实现，不能改变第三方许可。

参考 ZIP 为 10,102,665 字节，解压总计 13,554,767 字节，其中媒体 10,084,179 字节，约 74.4%；src 目录 2,117,121 字节，test 目录 926,831 字节。参考包的大小主要由图片和动图影响，不能据此判断业务能力多少。本项目不打包依赖、媒体、私人资料或求解器来凑 9 MB。

参考归档 SHA-256：

```text
30700d7afb83638d0e3f80f2e8c74186878aeddf15127812872ea5226117ca7d
```

### 可复核口径

1. 源码选 `.ts/.js/.mjs/.cjs`；排除 test/tests、测试文件、声明文件、依赖、构建产物、媒体和 Git。
2. 每个文件计算原字节 SHA-256，检查确切相同文件。
3. 词法分解源码，删除注释和空白；保留标识符、字符串、数字和标点。模板字符串整体视为一个 token。
4. 枚举连续 40 个 token 的窗口，以摘要集合比较；统计本项目命中窗口比例以及被命中窗口覆盖的 token 比例。
5. 修改前后均检查。本次详细聚合报告由维护者保留；不分发参考源码。

基线 13 个源码文件、41,862 字节；与参考的 668 个候选源码文件比较，确切相同文件为 0，40-token 窗口命中为 0。升级后比较 19 个源码文件、112,064 字节、23,072 个 token、22,331 个窗口：确切相同源码文件 0；命中窗口 0（0%），覆盖 token 0（0%）。数据对应 0.2.0 版本；仅指下面定义的筛查口径。

**结果不是版权鉴定。** 不存在通用的“低于某百分比就不侵权”阈值。短通用写法、语义相似但文本不同的实现、模板内代码、重排或跨语言改写可能无法检出。没有观察到重复片段，只代表这个固定算法和范围内的检测结果，不能声称法律上绝对原创。
